Schedule Heat Map

University of Cincinnati

Identify meeting times that work for the greatest percentage of students based on their class schedules and travel time between locations.

1. Prepare Schedule File

Open the Schedule Heat Map report in CaRT .

  1. Enter the student UCIDs (M#s) you want to analyze.
  2. Select the appropriate term. The report defaults to the current term.
  3. Click Apply.
  4. Below the results, select Export → Data → CSV.
  5. Download and open the Schedule Heat Map File Prep Tool .
  6. Click Enable Macros. If Excel then shows a red SECURITY RISK banner, close Excel.
  7. Right-click the downloaded file → Properties → check Unblock → Apply → reopen the file and click Enable Macros again.
  8. Open the CaRT CSV and copy the full export.
  9. Paste the full CaRT CSV export into the File Prep Tool beginning in cell A15.
  10. Click Prepare File for Upload and save the de-identified CSV it creates.
Important: Do not upload the original CaRT export. Upload only the de-identified CSV created by the Schedule Heat Map File Prep Tool. The prepared file replaces student UCIDs with anonymous student IDs.

2. Upload Schedule

Upload the de-identified CSV created by the Schedule Heat Map File Prep Tool. The number of students will be calculated automatically from the Anonymous Student ID column.

Buffers are added before and after each class meeting to account for travel time. Recommended UC defaults are: West/Online = 15 minutes, East/Victory = 25 minutes, Blue Ash/Clermont/Off Campus = 40 minutes, Other = 25 minutes.
