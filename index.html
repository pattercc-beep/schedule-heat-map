Schedule Heat Map

Identify meeting times that work for the greatest percentage of students based on their class schedules and travel time between locations.

1. Prepare Schedule File

Open the Schedule Heat Map report in CaRT .

  1. Enter the student UCIDs (M#s) you want to analyze.
  2. Select the appropriate term. The report defaults to the current term.
  3. Click Apply.
  4. Below the results, select Export → Data → CSV.
  5. Open the exported CSV file.
  6. Delete Column A, which contains the student UCIDs.
  7. Save the de-identified file before uploading it below.
Important: Do not upload student UCIDs. Before using this tool, confirm that Column A containing the student UCIDs has been deleted from the exported file.

2. Upload Schedule

Upload the de-identified CSV or Excel file after removing the UC ID column.

Enter the number of UCIDs you submitted in CaRT. This is used to calculate the percentage of students available.
